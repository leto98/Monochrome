# Monochrome

A minimalist monochrome 3D exploration game prototype built with Godot 4.

## Current prototype

- Dark, foggy 3D environment
- Simple player character
- WASD or arrow keys to move
- Space to jump
- Shift to run

## Cloud builds

GitHub Actions is configured to export Windows and Linux builds when code is pushed to `main`. Open the repository's **Actions** tab, select a successful build, and download the build artifacts.

This is an early prototype; the scene and export pipeline may need adjustments as development continues.
